# Kutsal Kitaplar (Holy Books)

Quran, Bible, Torah and Psalms in one clean, free, ad-free Android app.

Turkish content is bundled on-device and works fully offline.

## Features

- Quran — Elmalılı Hamdi Yazır translation (public domain), offline in Turkish
- Bible, Torah and Psalms — 1941 translation (public domain), offline in Turkish
- 51-language interface; Quran and Bible translations from open sources
- 5 reading modes: scroll, page, book, flowing text, focus
- Read-aloud (text-to-speech)
- 68 cross-scripture topics
- Reading plans with completion certificates
- Verse of the day and daily reminder notification
- Notes and bookmarks
- 5 themes, adjustable font size, dark mode

## Privacy

This app collects no personal data. No accounts, no sign-up, no analytics
or tracking. All notes and reading progress stay on the user's own device.

Privacy policy: [docs/privacy-policy.html](docs/privacy-policy.html)

## Sources

Texts come from public-domain sources and open APIs; translator and
source are shown on every chapter.
